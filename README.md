# Sunita-Traders-Website
A clean, modern, and responsive front-end web application developed for Sunita Traders, a physical retail business based in Jaipur specializing in event-grade carpets, runners, and door mats. This platform enables customers to browse high-resolution catalog items, filter products by category, and place orders or inquiries directly via WhatsApp and custom callback forms.
# Key Features
# 1. Interactive Product Catalog: 
Filterable categories showcasing carpets, designer runners, and door mats with high-resolution visual cards.   
# 2. WhatsApp Integration: 
Direct click-to-chat WhatsApp CTA buttons for seamless instant ordering, product inquiries, and wholesale quotes.   
# 3. Custom Callback Request Form: 
Integrated modal form allowing customers to select specific product categories and request direct contact.   
# 4. Location & Contact Integration: 
Embedded Google Maps view and direct shop location details for offline store visits.   
# 5. Responsive Layout: 
Dynamic UI optimized across standard screen dimensions for smooth navigation.   
# 6. Customer FAQ & Information Section: 
Accordion/list section resolving common customer queries regarding deliveries, custom cutting, and color accuracy.   
# 7. Tech Stack Frontend: 
HTML5, CSS3, JavaScript (ES6+)UI Framework / Styling: Custom CSS / Flexbox & CSS 
# 8. Grid Integrations: 
WhatsApp Web API, Embedded Google Maps API
